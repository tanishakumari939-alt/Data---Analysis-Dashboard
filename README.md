# Healthcare Data – Analysis(Interactive Dashboard creation using MS Excel)
## Project Objective
The objective of this Healthcare Data Analysis project is to analyze patient data to identify meaningful insights into medical conditions, treatments, hospital performance, healthcare costs, patient outcomes, length of hospital stay, insurance providers, and patient satisfaction.
## Dataset used
- <a href="https://github.com/tanishakumari939-alt/Data---Analysis-Dashboard/blob/main/Healthcare_500_Data%20(1).xlsx">Dataset</a>
## Question (KPIs)
-	What is the total  healthcare revenue/billing amount?
-	What is the average waiting time for patients?
-	What percentage of patients are male vs. female?
-	Which treatment has the best recovery/improvement outcome?
-	Which combination ofmedical condition + treatment has the highest average bill?
-	What are the top 5 hospitals based on patient satisfaction?
-	Which hospital provides the best combination of low average bill + high satisfaction?
-	How many male, female and other patients are there?
-	What treatment is most commonly used for each medical condition?
-	Which doctor has treated the most patients?
